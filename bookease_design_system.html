Do's and don'ts
✓ Do
Use DM Serif Display only for page headings and section titles — never for body text or buttons.
✕ Don't
Don't use pure white as a page background — always use the warm cream (#FAF7F2) for a premium feel.
✓ Do
Use amber (#E8A020) only for the single most important CTA on any given screen.
✕ Don't
Never put grey text on a cream background — use var(--slate-mid) (#5C5C54) minimum for readable contrast.
✓ Do
Forest green sidebar on every authenticated page. It anchors the entire layout and reinforces brand identity.
