# UI Design Specification: Modern SaaS Booking App

## 1. Core Identity & Vibe
*   **Vibe:** Modern SaaS (Trust & Clarity). Clean, reliable, and highly polished.
*   **Color Palette:**
    *   Primary: Indigo (`indigo-600` / `#4F46E5`), signaling trust and reliability.
    *   Background (Light Mode): Pure White (`#FFFFFF`) with off-white (`#F9FAFB`) sections.
    *   Background (Dark Mode): Deep slate (`#0F172A`).
    *   Text: Slate (`slate-900` for headings, `slate-600` for body).
    *   Semantic: Red (`red-500`) for destructive/errors, Emerald (`emerald-500`) for success.
*   **Typography:** `Inter` sans-serif font for excellent legibility and a sharp, no-nonsense SaaS aesthetic.
*   **Styling Details:** Subtle borders (`border-slate-200`), soft drop shadows (`shadow-sm`, `shadow-md`) for depth, slight rounding on components (standard `shadcn/ui` radiuses).

## 2. Layouts & Architecture

### Public Booking Flow (`/book/[slug]`)
*   **Layout:** Focused, centered single-card UI.
*   **Background:** Very subtle off-white or light gray pattern to make the booking card pull focus.
*   **Header:** Minimal. Just the Organization Logo and Name, with no complex global navigation to minimize drop-off.
*   **Flow:** Step-by-step wizard (stepper). 
    1. Select Service / Appointment Type
    2. Date & Time Selection (Interactive Calendar)
    3. Input Customer Details & Questions
    4. Confirmation / Success Screen.
*   **Mobile:** Crucial. Full-width cards, large tap targets, bottom-sticky action buttons.

### Admin & Organization Dashboard (`/admin/*`)
*   **Layout:** Split-pane interface.
*   **Sidebar (Left):** Collapsible vertical navigation holding primary links (Dashboard, Appointments, Configuration, Users, Settings).
*   **Top Bar:** Global Search, User Profile dropdown, Breadcrumbs.
*   **Main Content:** Clean white canvas with a max-width wrapper so data remains readable on ultrawide monitors.
*   **Data Presentation:** Premium data tables (`@tanstack/react-table`) for dense data views like appointments and users, featuring filtering, sorting, and pagination.

## 3. Technology & Theming Setup
*   **Component Library:** `shadcn/ui` customized to match the Indigo/Slate styling.
*   **Dark Mode:** Handled via `next-themes`, mapping light variables seamlessly to dark variables for a premium evening experience.
*   **CSS Framework:** Tailwind CSS.
